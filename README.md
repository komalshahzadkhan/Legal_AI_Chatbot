
# ⚖️ Legal AI Chatbot — Court Case Summarizer & Multilingual Translator

An AI-powered legal assistant built on Google Colab that simplifies complex court judgments into clear, easy-to-understand summaries and translates them into English, Urdu (اردو), and Roman Urdu.

## ✨ Key Features

• 📄 Court Case Summarization: Condenses lengthy legal judgments and case files into concise, structured summaries highlighting key facts, issues, and final verdicts.
• 🌐 Multilingual Support: Translates summaries seamlessly into three formats:
	• English (Clear & simplified legal English)
	• Urdu (اردو) (Native script for local accessibility)
	• Roman Urdu (Easy to read for everyday users)
• 💬 Interactive Chatbot Interface: Allows users to ask follow-up questions about the uploaded or pasted case text.
• ☁️ Google Colab Ready: Designed to run smoothly on Google Colab without requiring heavy local hardware.

## 🛠️ Tech Stack

• Language: Python 3
• Environment: Google Colab
• AI / NLP: Large Language Models (LLMs) / Hugging Face Transformers / LangChain (Edit according to the specific libraries/models you used)
• UI Framework: Gradio / Streamlit (Keep whichever you used, or remove if terminal-based)

## 🚀 How to Run on Google Colab

1. Open the Notebook: Click on the .ipynb file in this repository and select "Open in Colab".
2. Install Dependencies: Run the first setup cell to install all required Python libraries.
3. Add API Keys (If applicable): Enter your API key (e.g., OpenAI, Gemini, Hugging Face, or Groq) in the designated environment variable cell.
4. Run All Cells: Execute the remaining cells to launch the chatbot interface.
5. Summarize & Translate: Paste your court case text or upload a document, generate the summary, and select your desired output language (English, Urdu, or Roman Urdu).
